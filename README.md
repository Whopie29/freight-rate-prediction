# Freight Rate Prediction — Solution

## Repo structure

```
.
├── README.md
├── requirements.txt              # training deps (this repo's model)
├── train_model.py                # full training + inference pipeline
├── score.py                      # scorer provided by Spotter (unmodified)
├── data/
│   ├── train_test.csv
│   ├── validation.csv
│   ├── validation_predictions_template.csv
│   └── december_chart_inputs.csv     # will be overwritten in place by train_model.py
│                                       # (original saved alongside as *.original)
├── validation_predictions.csv    # generated output — final submission file
└── scorer_results/
    └── candidate_december.png    # generated by score.py
```

Place the four provided data files in `data/` with the underscore filenames above
(matching the original assessment package) before running.

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

`requirements.txt` here covers the model training pipeline (pandas, numpy,
scikit-learn, lightgbm, xgboost). The scorer's own dependencies
(`matplotlib`, `numpy`, `pandas`) are installed by the same file.

## Run

```bash
python train_model.py
```

This will:
1. Load `data/train_test.csv`, `data/validation.csv`, `data/december_chart_inputs.csv`.
2. Clean known data-quality issues (sign-flipped negative weights; missing
   `weight`/`market_index` imputed with training medians).
3. Engineer spatial, temporal, and interaction features.
4. Validate with a temporal hold-out (train Jan–Sep 2025, test Oct 2025) and
   5-fold cross-validation.
5. Retrain a LightGBM + XGBoost ensemble on the full 48,000-row development set.
6. Write `validation_predictions.csv` (12,000 rows, `load_id,predicted_rate`).
7. Fill `predicted_rate` into `data/december_chart_inputs.csv` in place
   (the original is preserved as `data/december_chart_inputs.csv.original`).

Then verify and produce the chart:

```bash
python -m pip install -r requirements.txt
python score.py --predictions validation_predictions.csv --december-predictions data/december_chart_inputs.csv
```

This validates both output files and writes `scorer_results/candidate_december.png`.

## Notes

- See `Freight_Rate_Validation_Report.docx` for the write-up of the data
  exploration, data-quality fixes, validation approach, and results, with the
  December chart embedded.
- The report's metrics/chart were produced with a scikit-learn
  `HistGradientBoostingRegressor` ensemble as a stand-in for LightGBM/XGBoost
  (same feature set and validation design) because the reporting environment
  had no package-index access. Running `train_model.py` locally with
  LightGBM/XGBoost installed reproduces the same pipeline and will give the
  intended production numbers/chart — swap those into the report before
  final submission if you want the LightGBM/XGBoost-specific figures.
